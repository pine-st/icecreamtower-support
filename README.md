# ICE CREAM TOWER Support Page

GitHub Pages用のサポートページ一式です。

## ファイル構成

- `index.html` : サポートページ
- `privacy.html` : プライバシーポリシー
- `css/style.css` : デザイン

## 公開前に変更する箇所

`support@example.com` を実際のサポート用メールアドレスに置き換えてください。

## GitHub Pages

リポジトリの Settings → Pages で、
`Deploy from a branch` → `main` → `/(root)` を選択してください。
